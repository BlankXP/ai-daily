## OpenAI 发布 GPT-Realtime-2 实时语音模型,128K 上下文+并行工具调用

OpenAI 在 API 中推出三款新音频模型——GPT-Realtime-2、GPT-Realtime-Translate、GPT-Realtime-Whisper,把语音从"快速轮转演示"推向"能真正完成工作的语音 Agent"。GPT-Realtime-2 是 OpenAI 首个具备 GPT-5 级推理能力的实时模型,实时上下文窗口从 32K 翻四倍至 128K tokens,支持并行工具调用并配有可听见的"工具透明"提示语(如"正在查日历""正在查询"),提供从 minimal 到 xhigh 的可调推理强度。在 Big Bench Audio 上,GPT-Realtime-2(high)较 GPT-Realtime-1.5 提升 15.2%;在 Audio MultiChallenge 上,xhigh 模式提升 13.8%。定价方面,音频输入 32 美元/百万 tokens,输出 64 美元/百万 tokens;翻译模型 0.034 美元/分钟,Whisper 变体 0.017 美元/分钟。早期客户包括 Zillow、Priceline、Vimeo、Deutsche Telekom、BolnaAI。

点评:128K 实时上下文 + 并行工具调用 + 可调推理强度,语音 Agent 终于具备"多轮工作流"的工程可行性,呼叫中心、现场作业、临床接入等场景的试点窗口已经打开。原文:[OpenAI](https://openai.com/index/advancing-voice-intelligence-with-new-models-in-the-api/) / [SEN-X](https://senx.ai/news/2026-05-10-daily-ai-news)

## OpenAI 开源 MRC 网络协议,超大规模 AI 集群的"操作系统级"突破

OpenAI 通过开放计算项目(OCP)发布了 MRC(Multipath Reliable Connection)规范,该项目由 OpenAI 与 AMD、博通、英特尔、微软、英伟达历时两年联合开发。MRC 在融合以太网上扩展 RDMA 并采用 SRv6 源路由,不再将每次传输固定在单一路径,而是将数据包喷洒至数百条路径并在目的地重组。它支持多平面网络——将 800Gb/s 接口拆分为八个 100Gb/s 平面——这意味着单台 64 端口交换机可扇出至 512 端口,仅用两层交换即可连接约 13.1 万张 GPU,而非传统方案的三到四层。OpenAI 表示,MRC 已在其最大的 NVIDIA GB200 超算上运行,包括位于德州 Abilene 的 Stargate 站点。

点评:从单路径到多路径喷洒 + 两层交换连接 13 万 GPU,MRC 把超大规模训练集群的网络架构从"凑合能用"推向"工程稳定",这是 AI 基础设施层面的"操作系统级"突破。原文:[OpenAI](https://openai.com/index/mrc-supercomputer-networking/) / [SEN-X](https://senx.ai/news/2026-05-10-daily-ai-news)
