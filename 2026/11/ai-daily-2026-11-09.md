# AI日报 2026-11-09

综述:过去 24 小时 AI 圈的新闻几乎被 Anthropic 一家承包——一边是 34 亿美元锁定 1.7GW 燃气发电机的算力军备,一边是两起安全事件(Claude Code 密钥大面积泄露、企业账户数据被第三方安全公司越权访问)。此外苹果被曝要把 Siri 改造成真正的智能体,AI 公司的股票供给成为资本市场的新话题。

## Anthropic 花 34 亿美元买下 1.7GW 燃气发电机,为数据中心抢电

据英国《金融时报》报道,Anthropic 在 9 月底与总部位于得克萨斯州的设备供应商 OnePWR Solutions 达成一笔约 34 亿美元的协议,接手后者此前向 Caterpillar 订购的 1.7GW 重型燃气发电机,并连带获得相应的工程与安装能力。交易不包含 OnePWR 公司本身,也没有员工转移。这被 Piper Sandler 形容为 AI 实验室最大规模的单笔发电设备采购。

点评:模型竞赛打到现在,瓶颈早就从“算力”转移到了“电力”。Anthropic 不买电厂而是插队买发电机,说明连排队等 Caterpillar 交付都成了稀缺资源。这笔钱比起它 IPO 文件里披露的数千亿美元基础设施承诺只是零头,但信号很明确:AI 基础设施军备竞赛已经卷到了发电机组层面。

## Claude Code 的“Don’t Ask Again”把密钥明文写进公开仓库

安全公司 Apiiro 扫描 GitHub 上 10.4 万份 .claude/settings.local.json 文件,发现 1122 份包含真实凭据,共 1379 个不同密钥,其中包括 379 个数据库密码、23 个 AWS 密钥和 42 个 GitHub/GitLab/npm token。原因是用户点“Yes, and don’t ask again”后,Claude Code 会把完整命令(含密码和 token)明文保存到该文件,该文件只会被加进本机的全局 git exclude,不会随项目走,提交后便留在 git 历史中。

点评:这属于典型的“方便换安全”设计坑。更尴尬的是,在 Apiiro 追踪的仓库里,539 个仓库的提交显示 Claude 自己是 co-author——AI 编程助手亲手把密钥推进了公开仓库。提醒所有用 Claude Code 的人:立刻轮换可能进过该文件的凭据。删文件没用,密钥泄漏了就是泄漏了。

原文:[The Hacker News](https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html) [Apiiro](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again)

## Anthropic 通报企业客户:第三方安全公司越权查看了账户数据

Anthropic 本周开始向企业 Claude 客户发送邮件,称一家第三方网络安全研究公司在 10 月下旬未经授权访问其内部系统,可能查看了账户 ID、组织 ID、套餐等级、用量与消费数据;对话内容、密码和支付信息未受影响。该公司已书面承诺删除数据,事件已通报韩国当局,但 Anthropic 未公布其名称与受影响组织数量。外界普遍猜测是此前自称 12 小时内攻破 Anthropic 的安全初创 Cathedral。

点评:这次泄露的数据本身不算敏感,但“第三方研究公司”这个身份值得玩味——安全研究员主动打进去、被发现、发通知,整个过程中 Anthropic 都处于被动。对企业客户来说,账户用量数据被外人看过一次,就该重新评估自己放在 Claude 工作区里的敏感信息了。

原文:[MLQ.ai](https://mlq.ai/news/anthropic-emails-enterprise-customers-that-an-outside-security-firm-may-have-viewed-their-contact-plan-and-spend-data/)

## 彭博:苹果计划最快明年让 Siri 变成真正的智能体

据 Mark Gurman 的 Power On 通讯,苹果 CEO John Ternus 在闭门会议上向软件主管 Craig Federighi 施压,要求 Siri 跳出“逐次对话”的框架,转向能跨对话追踪目标、自主推进任务的智能体形态,对标 OpenAI 的 Dots、Meta 的 Muse 和 xAI 的 Grok。为此苹果把 iOS 28 首个里程碑的排期从“4 周编码 + 4 周集成”改成“6 周编码 + 2 周集成”,最快明年就可能见到成品。

点评:个性化 Siri 刚随 iOS 27 落地,现在又要转向 agentic,节奏确实是被市场逼的——Dots 和 Muse 已经在“替你干活”了,Siri 还停留在问答层。不过苹果手里有 App Intents 这套现成的应用控制层,做智能体不一定非要走 computer-use 的笨办法,这是它少数能后发制人的地方。

原文:[9to5Mac](https://9to5mac.com/2026/11/08/apple-working-on-agentic-siri-ai-next-year-report/)

## AI 公司今年已卖超 3000 亿美元股票,还有约 1000 亿在路上

The Information 报道,2026 年 AI 公司已通过股票和强制可转债融资超过 3000 亿美元,另有约 1000 亿美元正在筹备,其中还不包括 Anthropic 即将进行的 IPO。报道发布前,市场刚经历一轮 AI 股抛售,Anthropic 的 IPO 估值讨论也从 2 万亿美元滑向 1.1 万亿到 1.3 万亿美元区间。

点评:这是 AI 资本狂欢的另一面:一级市场估值再高,最终都要二级市场接盘。Anthropic 的招股书已经让机构看到了“营收大涨、净亏数百亿美元”的真实账本,接下来几周这批 IPO 定价,会是检验 AI 泡沫成色的关键一役。

## 亚马逊重组家用机器人团队,瞄准新一代家庭机器人

CNBC 通过职位信息分析发现,亚马逊已把 Fauna Robotics 纳入新成立的 Personal Robotics Group,团队大部分来自原 Astro 项目,并引入了一位 MIT 机器人专家。Fauna 是亚马逊今年 3 月收购的纽约初创,其产品是 3.5 英尺高的人形机器人 Sprout。职位描述显示新品将能在动态家庭环境中自主导航、与家庭成员协同。此前 Astro 定价 1450 美元,仅售出几千台,消费版已被放弃。

点评:Astro 的教训是“价格贵、能力弱”,但亚马逊没放弃家用机器人这条线,转而用收购补齐硬件能力。Sprout 从商用和研究场景转家用是个合理的中间路线,只是“家用机器人”至今还没有谁真正跑通,这次押注仍需耐心。

原文:[CNBC](https://www.cnbc.com/2026/11/08/amazon-home-robot-fauna-sprout.html)

## Devin CLI 新构建被发现暗藏五档 Silicon 模型家族

FourWeekMBA 逆向 Cognition 于 11 月 7 日发布的 Devin CLI 构建(3000.12.28),发现其中列出了 silicon-low、silicon-medium、silicon-high、silicon-xhigh、silicon-max 五个模型标识,而 10 月 30 日的构建里完全没有。X 用户把编码 claude-donut-eap 映射到 silicon-high,据此猜测新模型来自 Anthropic。目前 Anthropic 和 Cognition 都没有回应,也没有任何官方宣布。

点评:纯属“拆包吃瓜”,但两个细节值得注意:五档分级与 Anthropic 官方文档里的 effort 级别命名一致,而且 Devin 的构建里一直混着多家模型商的身份标识。如果 Silicon 真是 Anthropic 的新模型,这种从 CLI 包里泄露的节奏,倒越来越像行业惯例了。

原文:[FourWeekMBA](https://fourweekmba.com/ai-devin-clis-new-build-lists-a-silicon-model-in-five-tiers/)
