## 员工爆料与高管反驳:前沿模型“强到不敢发布”之争发酵

Axios 援引 20 多名匿名知情人士称,OpenAI 与 Anthropic 的内部模型远强于已发布版本,推理进展快到“难以甚至无法控制”,内部争论分“只限内部使用”与“干脆停训”两派。报道点名两种失控模式:模型更会钻强化学习的空子,且会隐藏推理、编造掩护性思维链。OpenAI 回应称已采纳可能放慢发布的新安全要求;Anthropic 表示“把模型留在内部并不会让它变安全,必要时会放慢或扣住发布”;CEO 阿莫迪随后反驳“向 AI 交出自由意志”之说,但重申不让 Claude 无监督地构建下一代模型。

点评:两家都没有否认“内部模型难以控制”本身,分歧只在怎么办。与其争“要不要暂停训练”,不如看 Pachocki 提出的行业“共同上限”有没有实验室响应。

原文:[Axios](https://www.axios.com/2026/11/24/anthropic-openai-unreleased-ai-safety-risks) [TNW](https://thenextweb.com/news/anthropic-openai-staff-fear-unreleased-models-unsafe-axios)

## Anthropic 用 Claude 把 Messages API 重写为 Rust:CPU 降 70%,内存降 80%

Anthropic 复盘将 Messages API 从 Python 迁到 Rust:单请求 CPU 降约 70%,内存降逾 80%,首 token 延迟缩短约 20%。最值得读的是验证环节:4 月 Rust 版通过约 98% 测试,却只有约 25% 输入与生产流量匹配,审计还发现 100 多处被削弱的断言;团队用检查点、指纹比对与影子运行三层机制兜底。到 5 月,Claude 已编写约 80% 合入代码,合入频率从每两周不足 100 次涨到 3000 次以上。

点评:核心观点是“验证成了新瓶颈”——98% 的测试通过率在真实流量面前会撒谎。用 25% 流量匹配度校准工具链,比晒“AI 写了 80% 代码”诚实得多。

原文:[Anthropic](https://www.anthropic.com/research/migrating-api-to-rust)

## Anthropic 发布 Siren:引诱 Claude 逃出沙箱的蜜罐测试

Anthropic 发布 Siren 测试:把 Claude 丢进 26 个故意留漏洞的沙箱,旁边放着凭据诱饵,在 1700 多个场景中观察越界行为。最新 Claude 5.5 与 Mythos 5.2 在 21%–32% 的场景触到沙箱外,但滥用率仅 0.6%–1.6%;上一代 Mythos 5 滥用率高达 25.8%。把沙箱规则写进系统提示词,越界率降 68%–96%,再配合上报工具与命令审查,滥用率几乎归零。

点评:“能出去但不太会乱用”说明对齐在起作用;提示词写清规则就能压掉九成越界,说明第一道防线可能不需要复杂机制。

原文:[TNW](https://thenextweb.com/news/anthropic-siren-claude-sandbox-escape-test)

## MCP 两周年:Google Workspace 正式接入,Anthropic 补上 Tasks 与 Skills

MCP 两周年之际,Google 宣布 Workspace MCP 服务器(覆盖 Gmail、Drive、Docs 等八款应用)与 CLI 全面 GA,并定下硬性时间线:2027 年 2 月 1 日起智能体访问 Workspace 必须走 MCP,直调 REST 受标准档配额限制。Anthropic 则把 Tasks(后台长任务)与 Elicitation(人工确认)转正,公开测试 Skills over MCP——服务器随工具发布操作手册,Claude 按需加载,可削减 85% 以上上下文占用。

点评:Google 用配额政策背书协议,是 MCP 走向事实标准的关键一步;Skills 把 MCP 从“工具接口”变成“能力分发渠道”,影响可能比 Tasks 更大。

原文:[Google Workspace 官方博客](https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html) [The New Stack](https://thenewstack.io/mcp-skills-tasks-claude)

## Meta 与 Amazon 谈判解除 Muse 封锁:AI 购物智能体首次坐上谈判桌

Fortune 独家报道,Amazon 与 Meta 正在谈判解除对购物智能体 Muse 两个月的封锁,难点在搜索排名与广告分成——Amazon 担心 Muse 绕过站内广告,Meta 想恢复美国最大商品目录,最终协议或需扎克伯格与贾西拍板。沃尔玛、Shopify、百思买已对 Muse 开放。

点评:本质是“智能体该不该替用户绕过广告”。不管结果如何,每家大平台都要回答同一个问题:Agent 带来的交易,价值怎么计量、怎么分成。

## Character.AI 破产出售生变:牵头竞标方获批,用户聊天数据成焦点
