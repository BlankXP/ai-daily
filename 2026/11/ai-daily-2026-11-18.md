# AI日报 2026-11-18

过去 24 小时,AI 行业的动静集中在资本市场与模型产品两端:Anthropic 今晚将给 IPO 定价,若按发行区间上限计算将是史上第二大 IPO;Isomorphic Labs 拿下 50 亿美元 C 轮。产品侧,OpenAI 发布 GPT-6.2 Astra 与 Sol 并降价两成,谷歌把 Gemini Tasks 免费开放给六个国家;安全侧,Codex 挖出 OpenJDK 高危漏洞,当天即获修复。Nvidia 则在 CEO 动荡的背景下交出了超预期财报。

## Anthropic 进入 IPO 定价倒计时,或成史上第二大 IPO

Anthropic 11 月 17 日提交 S-1/A 第三修正案,确认发行价区间每股 70–78 美元、共 8.25 亿股 A 类股,按上限募资约 644 亿美元,仅次于 SpaceX 今年 6 月的 IPO,将是美股史上第二大 IPO。纳斯达克已批准其以代码 ANT 挂牌,预计 18 日晚定价、19 日首日交易;随 IPO 同步的还有约 260 亿美元私募配售,Nvidia 与 Google 各认购约 100 亿美元、AMD 约 25 亿美元。

点评:一家以 9650 亿美元估值(5 月 H 轮)走到公开市场的 AI 实验室,意味着这轮资本热潮进入兑现期;芯片厂集体认购,更像是把客户关系写进股权结构。它的定价结果,也会成为 OpenAI 明年 IPO 的市场锚。

## OpenAI 发布 GPT-6.2 Astra 与 Sol,旗舰 API 降价两成

OpenAI 11 月 17 日上线 GPT-6.2 Astra 与 GPT-6.2 Sol,面向 ChatGPT Work、Codex 与 API 开放。Astra 定价每百万输入/输出 token 8/40 美元,比 GPT-6 Astra 低 20%,缓存输入降至 0.4 美元;Sol 维持 2/10 美元。两款模型上下文窗口 105 万 token,支持文本与图像输入。OpenAI 称 Astra 在 Agents’ Last Exam 上比 GPT-6 Astra 高 5.2 分、成本不到三分之一,比 Claude Fable 5.2 高 5.5 分、成本仅约 5%;Sol 在 FrontierCode 2.0 上以约五分之一成本拿到与 Astra 差 0.5 分的成绩。

点评:这一代的看点不在绝对分数,而在按任务成本计的价格曲线:OpenAI 把竞争拉到成本效率维度,直接对标 Claude Fable 5.2。对开发者来说,同样预算能跑的 agent 任务量明显变多了。

原文:[OpenAI](https://openai.com/index/introducing-gpt-6-2-astra-sol/)

## Nvidia 交出超预期财报,黄仁勋表态愿回归

Nvidia 11 月 17 日盘后发布 2027 财年三季度财报:营收 1158 亿美元,同比增 103%、环比增 20%,高于预期的约 1090 亿美元;non-GAAP 每股收益 2.68 美元、GAAP 2.70 美元,双双超预期;Q4 指引 1300 亿美元上下 3%。这是黄仁勋 11 月 12 日辞任 CEO 后的首份财报,CFO Colette Kress 以临时 CEO 身份主持电话会。同日黄仁勋声明,若董事会认为符合各方利益,他很荣幸回归;据 CNBC 报道,董事会仍在调查涉出口合规问题,暂未考虑让其回归。公司股价自 10 月高点已回落约三成半。

点评:财报本身没有悬念,AI 基建需求依然爆炸;真正的变量是治理——CEO 空缺、董事会调查与监管问题叠加,再好的数字也压不住估值下杀。Kress 在电话会上如何回应这些,比营收更重要。

## Codex 挖出 OpenJDK 高危漏洞 Java4Shell,当天即修复

安全公司 Calif 11 月 17 日披露 CVE-2026-114938(Java4Shell):OpenJDK HotSpot 中用于 Base64 解码的手写 AVX-512 汇编存在堆破坏,未认证攻击者可远程执行代码,CVSS 4.0 评分 9.2,影响 Java 17/21/25 自 17.0.6 起约四年的版本。研究员 Quang Luong 用 OpenAI Codex 定位漏洞约 1 小时、写出首个利用再花 2 小时,token 成本不到 200 美元,演示覆盖 Jenkins、Jira、Confluence 等常见中间件的未认证 RCE。OpenJDK 与 Oracle 当天发布修复(JDK 17.0.21.1 等),截至披露日未见野外利用。

点评:这是 AI 找漏洞从演示走向常态的又一步:几百美元成本、当天出利用、当天出补丁,节奏完全是机器速度。Java 服务端存量巨大,建议尽快评估升级;这类漏洞的披露到修复周期只会越来越短,运维的打补丁手速得跟上。

原文:[Unite.AI](https://www.unite.ai/calif-uses-ai-to-find-java4shell-as-openjdk-and-oracle-ship-fixes) [calif.io](https://calif.io/java4shell/)

## Gemini Tasks 免费开放六个国家,谷歌把 agent 做成默认功能

谷歌 11 月 17 日宣布,Gemini 的 Tasks 功能(原代号 Spark)对美国、日本、韩国、加拿大、澳大利亚、印度六国用户免费开放,此前需要 AI Pro 订阅;通话与支付功能暂仅限美国。Tasks 基于 Gemini 4 Hydrogen 执行多步任务,运行在硬件隔离的虚拟机中,涉及支付需用户确认;用户在应用首页把 Chat 切换到 Task,即可把任务托管给后台 agent,完成后收到通知。

点评:谷歌把能干活的 agent 从订阅卖点变成免费默认能力,和 OpenAI 打的是同一场仗:agent 正在成为聊天应用的标配。隔离 VM 的设计值得注意——浏览器里的 agent,安全与可用性会是一对长期矛盾。

原文:[9to5Google](https://9to5google.com/2026/11/17/gemini-tasks-free)

## Isomorphic Labs 融资 50 亿美元,创 AI 制药单轮纪录

## Claude Mythos 三天完成 AMD GPU 移植,CUDA 护城河被动摇?

Anthropic 在 IPO 路演材料中披露,Claude Mythos Preview 约用三天把自家模型在 AMD MI355X GPU 上的 prompt processing 提升到可用水平,几乎 100% 的 kernel 由模型自主移植或编写,基本无需人工干预;传统做法需要数十名工程师干 6–12 个月。Anthropic 已把 Nvidia、AMD、Google TPU、AWS Trainium 当作统一计算池管理,但未公布 AMD 与 Nvidia 的性能对比,也未说明是否覆盖 decode 阶段。

点评:如果 AI 自己就能几天写完 kernel,CUDA 的软件生态壁垒确实在被侵蚀。但这个数字出自路演材料,口径只覆盖 prompt processing,离全面可用还有距离;真正的验证要等明年 MI450 规模落地后能否复现。

## LanceDB 完成 5750 万美元 B 轮,多模态训练数据基建升温

开源多模态数据库 LanceDB 11 月 17 日宣布完成 5750 万美元 B 轮,Bessemer 与 Innovation Endeavors 联合领投,累计融资 9850 万美元。公司主打基于开源 Lance 格式的多模态 lakehouse,把图片、视频与结构化数据放进同一套存储,服务于训练数据准备与数据加载,客户包括 Netflix、Microsoft AI、Runway 与 Midjourney。

点评:训练数据准备是模型开发里最脏最耗时的环节,这轮钱投的是多模态数据管道这个隐形瓶颈。对做视频生成与世界模型的团队,Lance 这类格式正在成为事实标准之一。

原文:[SiliconANGLE](https://siliconangle.com/2026/11/17/lancedb-raises-57-5m-to-accelerate-ai-model-training-with-multimodal-data-platform)
