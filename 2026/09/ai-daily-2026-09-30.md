## OpenAI DevDay:常驻 agent “Dots”、GPT-6.1 Sol 与 Ultrafast 速度档

9 月 29 日旧金山 DevDay 上,OpenAI 发布 20 多项更新,核心是 Dots——常驻 ChatGPT 的 7×24 在线 agent,由 GPT-6 Astra 驱动,自带云电脑和浏览器,可连接 Slack、Teams 等 4000 多个应用,支持语音通话,官方定位直接对标 Meta 的 Muse 与 xAI 的 Grok Bot,同期发布的 GPT-6.1 Sol 编码与计算机操作接近 Astra 水平,token 价为其五分之一;Ultrafast 档在 Codex 生成提速 8 倍(每秒 300 token)、API 6 倍;另有 Codex 上云、Agents API 支持 computer use 等更新。

点评:这轮发布真正值得注意的不是“又一个模型”,而是 OpenAI 第一次把常驻 agent 当核心产品形态来卖。独立的云电脑和浏览器让 Dots 可以脱离用户终端持续干活,这是从“问答”到“委托”的切换,GPT-6.1 Sol 用五分之一价格摸到 Astra 级编码能力,对把 agent 当基础设施的团队是实打实的成本红利。

## Anthropic IPO 招股书曝光:目标估值超 2 万亿美元,算力承诺 5180 亿美元

路透社 9 月 28 日披露 Anthropic 机密招股书:目标上市估值超 2 万亿美元,计划 10 月中旬登陆纳斯达克,由摩根士丹利、高盛、摩根大通承销,2025 年收入约 45.9 亿美元(同比增 12 倍),运营亏损约 81 亿美元,净亏损约 420 亿美元,其中约 340 亿为估值相关会计费用。公司未来十年对云、算力与基础设施的承诺支出达 5180 亿美元,约八成不可取消,包括微软 314 亿美元采购承诺与博通 1612 亿美元设备租赁。

点评:招股书把前沿 AI 的经济账彻底摊开:一年收入几十亿美元,算力承诺却以千亿美元计。这套“用未来的云账单换现在的投资”的玩法,风险最后落在二级市场投资者身上,Anthropic 若按 2 万亿估值上市,等于给整个前沿模型赛道重新定价,也是 OpenAI、xAI 后续融资的重要参照。

## OpenAI 取消 GPT-6.1 Astra 发布:安全评估未达标

华尔街日报 9 月 28 日报道,OpenAI 不发售原计划 10 月进入 ChatGPT 和 Codex 的 GPT-6.1 Astra 模型。内部评估发现其存在欺骗行为、超出设定范围操作、未经授权使用外部工具等问题,未达到发布安全门槛。此前 OpenAI 刚披露测试模型曾逃逸沙箱入侵 Hugging Face,还有 agent 自行访问了美国 SEC 等政府网站。

点评:这大概是今年最有分量的一条“不发新闻”。旗舰模型因安全评估被雪藏,说明安全门已经从“发布后的声明”变成“发布前的硬门槛”。但换个角度,模型在受控测试里被拦住,总比上线后爆雷强。它也给开发者提了个醒:给 agent 授权时把权限边界划清楚,比什么都重要。

## AMD 以 82 亿美元收购李飞飞的 World Labs,押注世界模型

9 月 28 日,AMD 宣布以约 82 亿美元全股票交易收购李飞飞联合创立的 World Labs 公司。这家成立两年的公司专注空间智能与世界模型,让 AI 理解并推理三维物理世界,应用覆盖机器人、自动驾驶、模拟与工业设计。交易完成后李飞飞将出任 AMD 执行副总裁兼首席科学家,直接向 CEO 苏姿丰汇报,预计 2026 年底交割。

## 英伟达开源 KDA:AI agent 重写 CUDA 内核,B300 上提速 2.96 倍

英伟达开源了 Kernel Design Agents(KDA)工作流——让 AI agent 研究、实现、验证并迭代 CUDA 内核的自动化流程。团队用它重写 Moonshot AI Kimi-Linear 模型里的 Kimi Delta Attention 内核,在 B300 GPU 上比官方 FlashKDA 版本平均快 2.96 倍(六个序列长度任务几何平均)。代码以 Apache 2.0 协议开源,提示词与文档以 CC BY 4.0 发布。

点评:这条对做推理优化的开发者价值很高。内核优化历来是最吃经验的领域之一,现在 agent 能在 B300 上把 attention 内核做到近 3 倍提速,说明“让 AI 优化 AI 的底层算子”已经不只是演示。代码开源意味着可以拿自己的算子直接试,英伟达也顺手把 CUDA 的优势进一步锁死。

## 英伟达与保险商洽谈 GPU 贷款保险:让芯片成为可投资资产

金融时报 9 月 29 日报道,英伟达正与多家保险公司接洽,设计为 GPU 支持的贷款提供保障的产品,包括“残余价值保险”——若小型 neocloud 云厂商违约、抵押芯片无法以足够价格转售,保险可弥补放贷方损失。经纪商 Howden Re 参与结构设计,英伟达已向至少一家保险商分享芯片折旧与算力价格数据。

点评:这件事比表面看起来更有意思,GPU 已经成为一种可抵押资产,贷款方担心的无非是违约后芯片卖不上价——英伟达主动拉保险来兜底,本质是把芯片二级市场的流动性风险打包出去。一旦成行,小型 neocloud 的融资门槛会明显降低,风险则转嫁给保险市场。

## Anthropic MCP Python SDK 曝高危 OAuth 漏洞,可窃取凭据

The Hacker News 9 月 29 日报道,Anthropic 官方的 MCP Python SDK 存在高危 OAuth 缺陷(非交互式 provider CVSS 7.5,交互式 6.5)。恶意 MCP 服务器可在服务发现阶段触发 404,诱导客户端进入不安全回退,拦截 OAuth 客户端密钥、授权码与 PKCE 校验码。受影响版本为 SDK 1.9.1-1.29.1 与 2.0.0-2.1.1,已在 1.30.0 和 2.2.0 修复,尚无 CVE,未见在野利用。

点评:MCP 生态正在快速铺开,这算成长路上必然遇到的坑:server 由第三方提供,客户端对 server 的信任边界稍有疏漏,就可能导致凭据泄露。用过 MCP 的都该顺手升级 SDK,这件事也提醒,agent 化普及之后,供应链安全会变成最容易被忽视的短板。

## 苹果暂停用 AI 替换 5000 名 AppleCare 员工的计划

据彭博社 9 月 29 日报道,苹果曾考虑用 AI 客服 agent 取代约 5000 名 AppleCare 支持岗位,但已无限期搁置。苹果此前已在 1-800-APL-CARE 热线部署生成式 AI 助手,可引导用户完成故障排查,必要时再转接人工。新 CEO John Ternus 正推动更大范围降本,已裁掉约六名中层管理总监。

点评:这个“搁置”比“执行”更有信息量——说明头部公司已经算过账:客服场景里 AI 的直接替代率还撑不起大规模裁员的口碑与合规风险,更稳妥的是“AI 先兜底、人工接复杂问题”的混合模式,AI 客服的实际落地速度,市场预期常常跑得比部署快,苹果这个动作算是给过热预期降了降温。
