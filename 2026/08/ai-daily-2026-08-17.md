# AI日报 2026-08-17

今天 AI 圈的大事集中在“钱”与“信任”两条线上：支付巨头 Stripe 以超过 70 亿美元的价格把 AI 模型网关 OpenRouter 收入囊中，试图掌握模型分发与计费的咽喉；国内，DeepSeek 的新版 API 定价从今日零时起生效，低价时代正式转向峰谷计价。与此同时，Anthropic 昨夜经历了一场波及 Claude 全线产品的大范围故障，而“AI 店长解雇员工”与“AI 诈骗成功率超过人类”两则消息，把智能体进入真实世界的两面同时摆上了台面。

## Stripe 以超 70 亿美元收购 OpenRouter，把 AI 账本握进手里

据 Bloomberg 报道，支付公司 Stripe 已敲定收购 AI 模型网关 OpenRouter，交易金额超过 70 亿美元，较该公司 5 月融资时的 13 亿美元估值溢价逾 5 倍。OpenRouter 聚合了 OpenAI、Anthropic、Google、Meta、DeepSeek 等 400 多款模型，号称服务约 800 万开发者，过去一年处理约 1500 万亿 tokens；其 CEO 曾自称 OpenRouter 是“AI 界的 Stripe”。这已是 Stripe 年内第二笔相关收购，此前它还拿下了用量计费公司 Metronome。

点评：交易说明资本的目光正从“模型本身”转向“模型分发与计费”这一基础设施层。谁掌握路由和账单，谁就可能在 agent 经济里长期收过路费。对开发者来说，网关集中化不是好消息，好在短期内多模型比价与切换仍很方便。

原文：[TechCrunch](https://techcrunch.com/2026/08/16/stripe-will-reportedly-acquire-ai-gateway-startup-openrouter-for-7b/)

## DeepSeek V4 系列 API 调价今日零时生效，新规执行峰谷计价

DeepSeek 上周公告的 V4 全系列 API 新价格自今日零时（北京时间）起生效：每天 9:00-12:00、14:00-18:00 被划为高峰时段，高峰价格是空闲时段的两倍。调价幅度因模型和 Token 类型而异，空闲时段最小涨幅 50%，部分条目涨了数倍，V4 Pro 高峰时段输出价格最高达 27 元/百万 tokens。随正式版一同发布的 V4 Pro（版本号 0813）还增强了 Agent 能力。

点评：以低价换市场的阶段过去了，DeepSeek 改用峰谷定价疏导推理负载。对国内开发者和 Agent 应用来说，任务排程与缓存命中策略从此要写进成本模型；这也侧面说明，在推理资源紧张的当下，价格信号比扩容见效更快。

原文：[东方财富网（21世纪经济报道）](https://wap.eastmoney.com/a/202608133840738352.html)

## Claude 全线服务昨夜大范围故障，Claude Code 与 Cowork 均受影响

北京时间今日凌晨，Anthropic 报告认证与登录异常，Claude.ai、Claude Code、Claude Cowork 及平台 API 出现大面积登录失败和服务降级。官方状态页先后确认了身份验证问题和性能下降，故障持续数小时后陆续恢复。

点评：Claude Code 已经是很多团队日常依赖的开发工具，这类故障对重度用户就是直接的生产力中断。Anthropic 这一周先因文本水印引发付费用户不满，又赶上这次故障，稳定性和信任问题比任何时候都更直接地摆在用户面前。

原文：[BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-confirms-claude-is-down-in-major-outage-affecting-multiple-services/)

## 首个“AI 店长解雇员工”案例落地：决定仍由人类确认

The Next Web 报道，旧金山 Andon Market 的 AI 店长 Luna——基于 Claude Sonnet 4.6 构建——在人类主管提示其查阅员工手册后，建议解雇一名 23 个班次里缺勤 17 次的员工，被认为是首个由大模型做出解雇建议的公开案例。解雇经公司复核后执行，所有员工仍与运营方 Andon Labs 签劳动合同；此前数月，Luna 已陆续给出渐进式警告并安排额外培训。

点评：媒体标题是“AI 开除了人类”，细节却更值得读：它连自己定下的考勤政策都忘了，靠人提醒才想起来。可靠性与责任归属，才是智能体进入管理场景的真正瓶颈；把解雇这类决定交给 AI，眼下的合规保障全靠公司自觉。

原文：[The Next Web](https://thenextweb.com/news/andon-market-luna-ai-store-manager-fires-employee)

## 研究：AI 聊天机器人的“杀猪盘”成功率，是人类骗子的两倍多

四所大学团队发表于 arXiv 的研究（经 Wired、VICE 报道）显示，在一周的“杀猪盘”模拟中，扮演骗子的 AI 聊天机器人说服了 46% 的受试者安装指定 App，而人类骗子只说服了 18%；尽管 22 名受试者中有 20 人猜到了对方是 AI，仍有约八成的消息发给了机器人。研究者认为优势来自持续跟进、记住个人细节，以及“表现出比真人更在意的关心”。

点评：模型没有发明新骗术，只是把耐心和记忆力用在诈骗场景，效果就碾压了人类。打击这类诈骗的检测与反诈宣传若还按人类诈骗犯的行为画像来设计，恐怕会明显滞后。

原文：[VICE](https://www.vice.com/en/article/ai-chatbots-are-better-at-scamming-people-than-human-scammers-study-finds/)

## Anthropic CEO 回应批评：AI 遭遇的反弹本质是信任危机

Dario Amodei 公开回应了投资人 Gavin Baker 的批评。Baker 在 All-In 播客与社交平台上称，Amodei 对 AI 风险的反复警告助长了美国公众对 AI 的反弹情绪，作为头部 AI 公司 CEO 应当更积极地替行业辩护。Amodei 反驳说，对 AI 公司最准确的批评是“尚未兑现造福世界的承诺”，责任在行业自己；他还反对“监管等于权力集中”的流行说法，认为在许多普通人看来，监管恰恰意味着约束企业权力。

点评：这是“行业领袖该唱衰还是唱多”的典型交锋。Amodei 把话题引回交付与信任，比单纯公关表态更有分量，但也回避了一个现实：从“AI 将治愈癌症”喊到今天，公众的不耐烦并非没有道理。

原文：[TechCrunch](https://techcrunch.com/2026/08/16/anthropic-ceo-says-ai-backlash-is-fundamentally-a-crisis-of-trust/)

## WSJ：患者用 AI 工具解开罕见病谜团，辅助诊断走向前台

华尔街日报报道，越来越多的患者、家属和医生开始借助 AI 工具参与罕见病诊断：Face2Gene 通过分析面部特征提示遗传病可能性，梅奥诊所的 AI 心电图系统曾识别出症状不典型的淀粉样心肌病；一位家长用 Face2Gene 确认了儿子和自己身上的毛发-鼻-指（趾）综合征。文章同时提醒，罕见病的训练数据稀少，AI 应辅助而非取代临床判断。

点评：罕见病误诊平均拖延数年，这类筛查工具把线索提前摆到医患面前，价值很实在。但当工具直接面向消费者时，“提示就医”和“给出结论”之间的边界，监管还没有跟上。

原文：[华尔街日报](https://www.wsj.com/health/ai-is-helping-patients-solve-medical-mysteries-3c2d7c25)
