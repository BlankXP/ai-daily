## Coding agent 集中爆出 SymJack 和 TrustFall 两个 RCE 漏洞:影响 Claude Code/Cursor/Gemini CLI/Copilot

Adversa AI 披露两个严重的 AI 编码 agent 安全漏洞:SymJack(符号链接劫持远程代码执行)一次性攻破 6 个 AI 编码 agent;TrustFall(一键 RCE)影响 Claude Code、Cursor、Gemini CLI 和 GitHub Copilot。同期,Microsoft 追踪到 Semantic Kernel 中提示注入导致主机级代码执行的攻击链。这些漏洞的集中爆发显示,2026 年 Q2 仓促上线的 AI 编码 agent 在开发者机器和 CI 运行器中已拥有真实权限,构成新的攻击面。NSA 及国际合作伙伴同日发布 Model Context Protocol(MCP)安全设计指南,覆盖认证、授权、服务器信任、传输控制、工具暴露和监控——MCP 正成为 agent-to-tool 集成的标准管道,但标准管道也会成为标准目标。同期还披露 CVE-2026-49257,mcp-pinot 中 10.0 严重度漏洞,默认禁用身份验证时可将 MCP 服务器绑定到所有接口。NVIDIA 在 6 月 DGX Spark 平台软件发布中推出 NemoClaw 开源 agent 部署环境,捆绑优化的本地模型、agent 编排框架和名为 OpenShell Runtime 的沙盒网关——这是对云端 agent 安全事件的直接回应,显示"本地 agent 部署"可能成为新趋势。

点评:Coding agent 集中爆 RCE 漏洞 + NSA 发 MCP 安全指南 + NVIDIA 推本地部署 NemoClaw,三个事件共同显示 agent 安全治理正从"模型对齐"扩展到"agent 执行环境";企业采用 AI 编码 agent 时必须把"agent 能执行什么"作为首要安全审计项,沙盒化和本地化部署将成为新标配。原文:[Tha Shed](https://tha-shed.com/ai-news-roundup-june-29-2026/) / [Adversa AI](https://adversa.ai/blog/top-agentic-ai-security-resources-june-2026/)

## Amazon 承诺 2030 年前向印度 AI 基础设施投入 480 亿美元:全球最大新兴 AI 市场争夺战

Amazon CEO Andy Jassy 在会见莫迪总理后于 6 月 25 日宣布 130 亿美元的追加印度投资,使 Amazon 2026-2030 年印度总投资达 480 亿美元,其中 210 亿美元专门用于 AI 基础设施。加上 Microsoft 的 175 亿美元、Google 的 220 亿美元、Meta 的 80 亿美元,美国四大科技巨头在印度的 AI 基础设施承诺总额已近 1000 亿美元。印度作为全球最大新兴 AI 市场,正成为美印战略 partnership 的关键支柱——美国科技公司通过 AI 基础设施投资获得印度市场准入和人才储备,印度则通过主权 AI 框架要求技术转移和本地化部署。这一投资潮与同期 Amazon 在印度投入 130 亿美元建设 AI 基础设施(覆盖模型训练、机器学习服务和本地开发者生态)、SAP 与 Google Cloud 联合部署企业商业流程智能体架构、Anthropic 在 Slack 中推出工作场景 AI 智能体等事件共同显示:AI 全球化正从"模型出口"演化为"基础设施出口",而印度作为"全球最大新兴 AI 市场正成为美中 AI 地缘博弈的关键战场"。
