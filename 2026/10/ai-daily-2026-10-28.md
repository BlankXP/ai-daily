# AI日报 2026-10-28

今日 AI 圈的重心几乎全在资本与算力端:Anthropic 正式递交 IPO 招股书,微软向约 6 万名员工提供自愿买断,Meta 宣布公司史上最大规模的股权融资;产品端 OpenAI 一天之内放出 GPT-6.1 Terra 和三项基础科学发现,节奏相当密集。

## Anthropic 递交 S-1,冲刺史上最大规模 AI 公司 IPO

Anthropic 于 10 月 26 日向美国 SEC 正式递交 S-1 注册声明,计划以代码 ANT 登陆纳斯达克,高盛与摩根士丹利牵头承销。招股书显示,公司 2026 上半年营收 16.3 亿美元,是上年同期 1.16 亿美元的约 14 倍;同期净亏损 807 亿美元,其中 724 亿美元为可转债、SAFE 等公允价值变动带来的非现金损失。二季度经营收入 9.74 亿美元,为近六个季度首次转正。S-1 还披露未来算力采购义务约 4170 亿美元。发行价与估值尚未确定,媒体报道称其有望对标 SpaceX 去年夏天创纪录的 1.8 万亿美元 IPO。

点评:这份招股书把「营收暴涨、巨额非现金亏损、千亿美元算力负债」三件事同时摆上桌,市场要消化的是 AI 公司以负债换增长的典型剧本。真正值得盯的其实是二季度 9.74 亿美元经营利润转正——烧钱故事讲到最后,盈利模型第一次有了实据。

原文:[Anthropic](https://www.anthropic.com/news/s1-sec) [CNBC](https://www.cnbc.com/2026/10/26/anthropic-ipo-live-updates-ai-s-1-filing.html)

## Meta 拟发行最高 950 亿美元股票为 AI 基建融资

Meta 周一宣布启动约 350 亿美元的承销发行,包括 Class A 普通股与强制可转换优先股存托凭证,并计划通过市价发行(ATM)项目再募最多 600 亿美元的无投票权 Class C 股票,合计最高 950 亿美元,为公司史上最大规模股权融资。Meta 同时披露英伟达、AMD、博通有意认购最多 50 亿美元股份。公司 2026 年资本开支预期区间上调至 1350 至 1450 亿美元。

点评:连 Meta 这种前三季度经营现金流近 970 亿美元的公司都要靠发股票补血,可见 AI 基建的资本黑洞已经吞到头部玩家的融资结构里。用无投票权 C 类股融资以保住扎克伯格的控制权,这个设计比融资金额本身更值得琢磨。

原文:[CNBC](https://www.cnbc.com/2026/10/26/meta-stock-offering-ai.html) [Bloomberg](https://www.bloomberg.com/news/articles/2026-10-26/meta-seeks-up-to-95-billion-in-equity-to-fund-ai-spending)

## 微软向约 6 万名员工提供自愿买断,占比超四分之一

微软周一宣布,向美国、加拿大、英国、印度的约 6 万名员工(副总裁及以下级别)提供自愿离职买断方案,约占全球 22.3 万全职员工的 27%。涉及 Windows+Devices、Xbox、财务、人力资源以及 AI 体验与 Copilot 等团队;数据中心运营、商业销售、营销与安全部门被排除在外。公司今年预计资本开支达 1750 亿美元,市场对其 AI 投入回报的质疑正在升温。

点评:「数据中心运营被排除在买断之外」是这条消息里最有信息量的一句,裁员剪刀差直接标出了微软认定的核心资产。在 AI 投资回报承压的当口,自愿买断比强制裁员更温和,但一次覆盖四分之一员工的动作摆出来,信号已经足够直白。

原文:[路透社](https://www.reuters.com/technology/microsoft-is-offering-buyouts-around-60000-employees-business-insider-reports-2026-10-26) [CNBC](https://www.cnbc.com/2026/10/26/microsoft-msft-voluntary-buyouts.html)

## OpenAI 发布 GPT-6.1 Terra:视觉推理加电脑操作,API 价格减半

OpenAI 10 月 26 日发布 GPT-6.1 Terra,一款面向日常办公场景的快速模型,主打详细视觉推理、精确的电脑操作与更自然的文字能力,已面向 ChatGPT Work 与 Codex 的 Plus、Pro、企业、教育用户开放。标准 API 价格比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%。官方称其在 Agents’ Last Exam 上以约三分之一成本比 GPT-5.6 Terra 高出 15 个百分点,以 GPT-6 Astra 十分之一的单价做到相近水平,任务完成速度约为后两者的三倍。同日发布了对应系统卡。

点评:Terra 这条产品线说明 OpenAI 开始把「性价比」当成正式的产品维度来做,而不是促销话术。50% 降价加上电脑操作定位,明显冲着高频自动化场景去,对开发者来说这是实打实的成本利好。

原文:[OpenAI](https://openai.com/index/introducing-gpt-6-1-terra/)

## OpenAI 公布三项基础科学发现,启用外部学者协作发布机制

OpenAI 同日发布三份研究结果:调和分析领域的「局部光滑化与 Kakeya 猜想」、复杂性理论领域的「指数时间假说不成立」、量子场论领域的「QCD 存在性与标准模型完备化」。公司明确表示这些是 AI 生成的原始研究数据,尚未经同行评审,并首次采用外部学者协作模式:数学结果直接公开;计算机科学结果由外部团队解读,自然语言证明与 Lean 形式化同步公开到 GitHub;物理结果交由外部团队撰写发布。OpenAI 不署名、不要求保密协议。

点评:如果「指数时间假说不成立」最终被证实,这是足以动摇计算复杂性理论根基的事件,学术界先组织外部团队核实再谈发布的姿态,等于给 AI 产出的结论兜了一层底。比起结论本身,这套「OpenAI 不拿学术 credit、让社区验货」的流程更值得行业抄作业。

原文:[OpenAI](https://openai.com/index/building-scientific-understanding-with-academic-communities/)

## 前 GitHub CEO 发布 Entire:面向 AI 智能体的 Git 平台

前 GitHub CEO Thomas Dohmke 创办的 Entire 周一正式上线其 AI 原生 Git forge,可托管、审查并发布 AI 智能体编写的代码,直接对标 GitHub。核心设计是用 Trails 取代传统 pull request:每次代码推送由智能体按可定制的评估标准打分;官方称其网络克隆速度可比 GitHub 快 3 倍。公司今年 2 月成立,曾以 6000 万美元种子轮成为开发者工具领域最大种子融资。

点评:智能体写代码的速度已经超过人类审查的速度,代码托管层迟早要为此重构,Entire 赌的正是这个拐点。GitHub 的 PR 流程默认「人类逐行看 diff」,这套假设在 agent 日均合并数万次变更的时代正在失效——Anthropic 自研源码控制系统,是同一个方向的信号。
