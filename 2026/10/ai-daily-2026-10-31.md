# AI日报 2026-10-31

过去 24 小时,AI 圈的注意力集中在安全与算力两端:Claude Code 官方扩展被投毒并植入 SSH 后门,成为今年最典型的 AI 供应链攻击样本;英伟达则开始为算力买家的债务当担保人,给 Anthropic 的 460MW 新机房背书。开源侧,Mistral 放出 1 万亿参数 Le Chonk 的权重,阿里云预告 Qwen4 下周发布;硬件端,台积电买下面板厂扩充 CoWoS,长鑫存储盈利转正并冲刺 HBM3E。

## Claude Code 官方 VS Code 扩展被投毒,植入 SSH 后门,最多 5000 开发者受影响

安全机构 OpenSourceMalware 披露,伪装成官方 anthropic.claude-code 2.1.313 的恶意版本 10 月 29 日出现在 Cursor 插件市场约 11 小时:它插入 66 行加载器,向 ~/.ssh/authorized_keys 写入攻击者控制的密钥,再用反向隧道和计划任务/LaunchAgent 实现跨平台持久化。Cursor 估计受影响用户最多 5000 人,Anthropic 已发布干净版 2.1.314。

点评:这起事件比普通恶意插件严重的地方在于顶着官方名头、靠自动更新流进开发者机器,攻击者拿到 SSH 密钥,基本等于整台开发机沦陷。插件市场的审核明显跟不上 AI 开发工具的分发速度,装过 2.1.313 的人按官方指引轮换凭据是必须的。

## Mistral 开源 1 万亿参数模型 Le Chonk,自称开源侧最强编程模型

Mistral 于 10 月 29 日发布旗舰模型 Large 4(绰号 Le Chonk)的开源权重。模型约 1 万亿参数、原生多模态,每 token 激活约 490 亿参数;在 Cognition 的 FrontierCode 2.0 上以 19.7% 领先全部开源模型,B3 智能体安全基准上可抵御 97.1% 的攻击,官方称推理 token 消耗比同类少 47%。权重已上 Hugging Face。

点评:Le Chonk 的意义不在参数大小,而在把编程、安全和推理效率同时做到开源第一梯队,而且全程在欧盟境内训练,对不想把代码交给美国 API 的公司是目前最现实的自托管选项。注意授权:自托管没问题,想拿它开云服务要单独谈商业许可。

原文:[Mistral AI](https://mistral.ai/news/mistral-large-4-oss/)

## 长鑫存储单季净利 544 亿元,计划两个月内试产 HBM3E

长鑫存储上市后首份季报:Q3 净利润 54.4 亿元人民币,营收 1187.1 亿元、同比增 613.2%,毛利率 89.53%,AI 需求推高 DRAM 价格是主因;第六代制程 DRAM 样品已通过验证。据路透,公司希望两个月内开始有限的 HBM3E 产出,但目前良率仅 20% 到 30%,SK 海力士约为 70%。

点评:盈利数字很漂亮,但 HBM 这道坎才是分水岭。普通 DRAM 赚钱靠行情,HBM 赚钱靠良率——20% 到 30% 的良率意味着大量晶圆报废,利润会被学习曲线吃掉。长鑫的全球 DRAM 份额一年翻倍到约 10%,扩产很凶,但在 HBM 良率追上来之前,估值本质还是周期股。

## 清华、智元、无问芯穹让 96 台真机互相学习,成功率超过人类平均

清华、智元机器人(Agibot)与无问芯穹(Infinigence AI)团队提出集体经验学习(CEL):让已部署的机器人共享执行经验、共同迭代同一策略,失败轨迹只作检索线索、不参与模仿。96 台智元 G2 双机械臂真机在 5 项任务上验证:两台从未参与训练的机器人 600 次试验成功率 97.5%,5 项任务全部超过 6 名人类操作员的平均水平,手机包装任务从 79.2% 提升到 98.3%。论文已挂 arXiv(2610.25736)。

点评:这算是数据飞轮在机器人身上的落地:机器人越多,收集的真实经验越多,策略越好,也不再需要人类专家逐台纠正。训练车队从 16 台扩到 96 台,成功率从 86.7% 涨到 98.3%,规模效应是实打实的。这方向如果成立,先卖机器人、再靠车队反哺模型的商业闭环就通了。

## 有人把整个 NES 主机编译进 Qwen3.5 权重,还能逐周期跑马里奥

开发者 dbreunig 发布 Nesformer:把 NES 的 CPU、内存和卡带 ROM 编译进一个普通 Qwen3.5 模型的 Gated DeltaNet 状态矩阵,模型通过逐步预测 6502 指令执行 token 的方式运行超级马里奥,输出与常规模拟器逐周期一致。项目约 4.66 亿 bf16 参数(仅 930 万非零),是此前 Qwenputer(CHIP-8/RISC-V)的续作,代码与权重均已开源。

点评:与其说这是模型学会了打游戏,不如说是把一台 1985 年的计算机塞进权重里当计算介质。实用价值谈不上,但它提醒一件事:状态空间模型的隐藏状态完全可以当成可编程的存储与计算单元,这种模型即硬件的思路,未来未必只出现在玩具项目里。
