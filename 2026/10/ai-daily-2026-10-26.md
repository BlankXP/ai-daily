# AI日报 2026-10-26

过去的 24 小时正值周末,AI 圈没有重磅新模型发布,主旋律是”钱”和”价”:OpenAI 与 Anthropic 的 API 降价潮被系统复盘,Apollo 首席经济学家抛出”AI 对非科技行业零回报”的报告,马斯克警告 200 多家 neocloud 将迎来洗牌;开源侧则有 33B 智能体编码模型和 Claude Code 沙箱的发布,外加一篇”10 年前的老 CNN 胜过前沿大模型”的医学诊断对照实验刷屏。

## 大模型 API 价格战复盘:数月内最高降价 80%,开源模型是外生压力

数据科学家 Max Woolf 在最新长文中系统梳理了 OpenAI 与 Anthropic 过去几个月的价格曲线:GPT-5.6 Luna 在 7 月 30 日直接砍价 80%(输入降至 0.20 美元/百万 token),9 月 22 日 GPT-6 Sol 与 Claude Opus 5.5 同日发布,双双把输入价压到 2–4 美元区间;一周后 GPT-6.1 Sol 再把缓存读取价砍半,整个模型家族累计比 6 月便宜约 75%。Anthropic 明说 Opus 5.5″推理所需算力比 Opus 5 更少,价格也反映了这一点”。Vercel 的网关数据显示,每 token 成本已降到 4 月的 43.3%。Woolf 认为这不是简单的互相压价:DeepSeek V4 Flash 系列以约 0.14–0.15 美元/百万 token 的输入价和 2% 的缓存读取费率充当价格锚,OpenRouter 上托管它的厂商从 5 月的 13 家涨到 29 家,开源模型才是这轮降价的外生压力。

点评:对做应用和 agent 的开发者,这是实打实的成本红利——同一模型降价 75%,同等预算下的用量可以翻几倍。更值得留意的是 Woolf 的观察:降价没有以质量缩水为代价,靠的是推理效率提升;如果这条路继续走下去,大规模数据中心建设的必要性反而会被削弱,这跟当下”算力无限扩张”的叙事是拧着的。

## Apollo 首席经济学家:AI 对美国科技行业以外的企业”零回报”

Apollo Global Management 首席经济学家 Torsten Slok 在 10 月 24 日发布的报告《No Signs of AI Payoff Outside the Tech Sector》中称,”这项技术对美国科技行业以外的企业没有带来任何财务回报”。他用三组数据支撑:2022 年以来科技七巨头的员工人均营收从约 55 万美元涨到近 80 万美元,而标普 500 其余 493 家公司七年来一直徘徊在 55 万美元左右;利润率同样只涨科技股;旧金山联储调整后的全要素生产率也没有显示 AI 拉动增长的迹象。报告还引用 Ramp 的数据,指出 AI 支出高度集中在少数公司、存在循环融资的迹象,并称主流企业正把 token 支出从”增长来源”重新定位为”压利润的成本中心”。经济学家 Brad DeLong 同日回应:同意宏观数字上还没体现,但认为用户剩余”巨大”,只是股东难以捕捉。

点评:这份报告是”AI 泡沫”阵营最近最有力的弹药,”S&P 493″的提法把争论焦点从模型能力拉回了商业回报。我的判断是两边各对一半:模型确实在快速变便宜(见上一条),但便宜不等于企业真用起来了;判断 AI 商业价值的最终标准,还是非科技行业的采纳深度,而不是科技公司自己的财报。

## SpaceX 完成 400 亿美元 GPU 债务融资,马斯克警告 200 多家 neocloud 将洗牌

马斯克周末在 X 上宣布,SpaceX 已敲定约 400 亿美元的可赎回债务融资,用于采购英伟达 GPU,交付期在 2027 年第一季度至第二季度;靠投资级评级、Starlink 现金流和发射收入才拿到这笔钱。他同时警告,债务市场对没有独立收入的 AI 公司”几乎关死了门”,”200 多家 neocloud 会经历小鱼级的死亡与整合,少数能活下来,但不会很多”。SpaceX 的 AI 业务(Colossus 数据中心加 Grok)已是财报亮点:Q3 营收 14.58 亿美元、同比增 161%,资本开支近乎三倍至 19.6 亿美元,Q4 预计 35–40 亿美元。同期融资环境确实在恶化:CoreWeave 信用利差走阔至困境水平,Firmus 撤回 IPO,OpenAI 本轮融资估值目标也从 1.4 万亿下调到 1.25 万亿。

点评:”钱”正在取代 GPU 和电力,成为 AI 扩张最稀缺的资源,英伟达黄仁勋上周也说过类似的话。neocloud 的商业模式——举债买卡、出租算力——在利率高位下格外脆弱,马斯克这话难听但方向没错:算力需求不缺,缺的是能撑到回本的资本。

## Nanbeige 开源 33B 智能体编码模型,自称 18/20 项基准领先 Qwen3.8-27B

背靠招聘平台 BOSS 直聘的中国实验室 Nanbeige(纳米北格)10 月 25 日在 Hugging Face 开源 Nanbeige4.3-33B:Apache 2.0 协议、33B 参数、512K 上下文,默认开启推理模式,BF16 权重约 66GB、4-bit 量化后约 20GB,可本地部署。模型卡自称在 18/20 项基准上领先同量级的 Qwen3.8-27B,包括 Terminal-Bench 2.1 的 80.9 对 73.0、DeepSWE 的 65.5 对 42.5、AIME 2026 的 95.2。它是 Nanbeige4.3 系列的”教师模型”,后续会蒸馏出更小的 3B 版本。

点评:需要注明这些数字全部来自模型卡自报,第三方还没有复现;”30B 量级加 agentic 编码加 512K 上下文加 Apache 2.0″这个组合本身就有意义——开源小模型正在把智能体编程卷成白菜价,正好呼应上面 OpenAI 和 Anthropic 的降价。

## Anthropic 开源 Claude Code 沙箱 sandbox-runtime,Apache 2.0 三平台支持

Anthropic 本周末开源了 Claude Code 底层使用的操作系统级沙箱 sandbox-runtime(简称 srt),以 npm 包 @anthropic-ai/sandbox-runtime 发布,Apache 2.0 协议。它在不依赖容器的情况下给任意进程施加文件系统与网络限制:macOS 用 sandbox-exec 加 Seatbelt 配置,Linux 用 bubblewrap 加网络命名空间,Windows 是 alpha 版,基于 Windows Filtering Platform 过滤器和 NTFS ACL。功能包括 allow-only 网络策略、Unix socket 白名单、实验性 TLS 终止(可对 HTTPS 做中间人检查)、凭据掩码、AWS SigV4 签名,还支持把 MCP server 直接换壳跑进沙箱。README 明确说这是”为 Claude Code 开发的更安全 AI agent 研究预览”,API 和配置格式可能还会演化。

点评:这是”把 agent 关进笼子”的具体工程实践,值得做 agent 开发的人直接抄——尤其 MCP server 沙箱化那一步:很多团队天天在跑不可信的第三方工具,却从没想过给它套一层网络白名单。

原文:[GitHub](https://github.com/anthropics/sandbox-runtime)

## 对照实验:10 年前的 CNN 在皮肤癌诊断上胜过 GPT-6 Astra 和 Claude Fable 5.1

伦敦 Guy’s 医院皮肤科顾问医生 Magnus Lynch 在个人博客公布了一项对照实验:用 200 个活检确诊的皮肤病灶(来自公开数据集 MILK10k),让 GPT-6 Astra、Claude Fable 5.1 和一个微调了约 20 分钟的 Inception v3(2015 年架构、单张 H100、68011 张图)做六分类诊断。结果 Inception v3 正确 125 例(62%),两个前沿大模型分别只有 84 例和 85 例(42%);30 个黑色素瘤里 CNN 认出 13 个,Astra 8 个、Fable 11 个。而且这个老 CNN 小到能直接在手机浏览器里用 WebGPU 跑。作者承认样本量小、Inception v3 远非 SOTA,大模型反而可能在训练数据里见过这些图。

点评:这个结果不说明大模型”不行”,而是点破一个行业心照不宣的事实:通用模型在窄领域识别任务上,往往打不过为这个领域专门训练的小模型。对做医疗等垂直场景的团队,把微调预算花在”小而专”的模型上,可能比追着通用旗舰跑更有性价比。

原文:[lynchlab.net](https://lynchlab.net/llm-skin-cancer)
