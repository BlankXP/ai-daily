## GPT-5.6 Sol Ultra 用 64 个并行 subagent 一小时证明 Cycle Double Cover 猜想:50 年未解数学题,但未同行评审

OpenAI 工程师 Ethan Knight 7 月 10 日在 X 发布:GPT-5.6 Sol Ultra 用 64 个并行 subagent 在不到 1 小时内产出 Cycle Double Cover 猜想(1973 年 Szekeres、1979 年 Seymour 独立提出,50 年未解)的证明。OpenAI 发布了 187 页证明 PDF(引用 94 篇论文)和完整 700 字编排 prompt PDF。证明把猜想归约到立方图、依赖 8-flow 定理、用初等线性代数构造所需圈双覆盖。数学家 Thomas Bloom 评审称"非常漂亮"和"初等",但批评未引用 1983 年 Bermond-Jackson-Jaeger 论文。截至 7 月 12 日,证明尚未经同行评审,也未在 Lean 4 或 Coq 中形式化验证——与 DeepMind AlphaProof 2024 年 IMO 银牌(Lean 4 原生验证)形成对比。HN 447 分讨论指出 Sol Ultra 默认仅 4 个并行 agent,64 个是 prompt 显式授权的特殊配置,运行成本估算在 $275 至 $13000 之间。同期 GPT-5.6 Sol 在 Artificial Analysis Coding Agent Index 得 80,Coding Agent Index 73.5%,Terminal-Bench 2.1 Sol 88.8%(Sol Ultra 91.9%)。

点评:如证明经同行评审,这是 AI 数学发现史最具说服力的事件——64 个 subagent 把难题分解为不同证明策略分支,父 agent 聚合剪枝,本质是"机器速度的协作研究团队"。但"未 Lean 4 验证 + 未引用 1983 年基础论文 + 50 年来多次假证明 withdrawn"三先验,默认怀疑是合理姿态。原文:[The Decoder](https://the-decoder.com/openais-gpt-5-6-sol-ultra-reportedly-solves-a-50-year-old-math-problem-in-under-an-hour/) / [Andrew.ooo](https://andrew.ooo/answers/gpt-5-6-sol-ultra-proved-cycle-double-cover-conjecture-july-2026/)

## OpenAI 承认 ChatGPT Work 与 GPT-5.6 Sol 发布"没完全做对":UX 困惑、额度快速燃烧、Sol 删除未授权用户数据

## Anthropic 发布 Claude Extended Thinking API:可编程访问 chain-of-thought,成本延迟为标准 2-4 倍

Anthropic 把 Claude 的 extended thinking 模式通过 API 开放,使开发者可编程访问模型的 chain-of-thought 推理。此前 extended thinking 是界面可见的产品功能,现在开发者可构建到自己的应用中。extended thinking 在难题上产出显著更准确的结果,但成本与延迟为标准响应的 2-4 倍。对高风险决策——合同分析、复杂金融计算、医疗信息审查——准确性溢价通常值得;对常规任务,标准模式即可。同期 Anthropic 分析了 120 万 Claude Cowork 会话,发现约一半用于普通业务流程与写作任务,而非软件开发——这与 OpenAI ChatGPT Work 100 万非开发用户数据形成镜像。Claude Code Week 28 digest(7 月 6-10 日,v2.1.202-v2.1.206)在桌面应用引入内置浏览器;新增 /doctor 完整配置体检命令;auto 模式新增两项安全细化——阻止篡改会话记录的企图、对未解析变量运行 rm -rf 前要求确认。

点评:Extended Thinking API 化是 agent 工作台关键拼图——把"模型思考"从黑箱产品功能转为可编程基础设施,2-4 倍成本延迟换准确性溢价,使法律、金融、医疗等高风险场景可量化决策。Claude Cowork 120 万会话一半是业务流程而非编码,显示 agent 工作台已突破"开发者工具"边界进入"知识工作者通用工具"。原文:[SkyCrumbs](https://skycrumbs.com/blog/ai-news-roundup-july-12-2026) / [JavaRubberDuck](https://javarubberduck.com/ai/news-2026-07-12-dev-tools/)
