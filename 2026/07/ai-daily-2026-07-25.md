## Black Forest Labs FLUX 3 多模态:图像 + 20 秒视频 + 同步音频 + 机器人动作预测一个骨干,FLUX-mimic 在奥迪生产环境部署

Black Forest Labs 7 月 23 日发布 FLUX 3,首个主要生成模型将 20 秒视频(含同步音频)、高端图像编辑、机器人动作预测通过一个联合训练骨干运行(而非拼接子模型)。核心架构:Self-Flow 使多模态同时学习。性能表现:720p 视频最长 20 秒(含原生音频);初期评估对 Runway Gen-4.5 偏好率 77%,对 Luma Ray 3.2 偏好率 93%。FLUX-mimic:在 FLUX 3 骨干上添加轻量级动作解码器,从视频生成学习获得的世界模型中间表示直接解码机器人动作,RTX 5090 单卡骨干处理 80ms 以下,整体反应速度 101ms(接近人类视觉反应速度)。奥迪生产环境部署:FLUX-mimic 已在奥迪生产环境部署,处理零件托盘装填(kitting)、电子控制单元(ECU)插入、密封与电缆等软质材料处理——传统自动化无法处理的工作。

点评:Black Forest Labs FLUX 3 是"首个主要生成模型将视频+音频+图像编辑+机器人动作通过一个联合训练骨干运行"的标志,Self-Flow 架构使多模态同时学习;对 Runway Gen-4.5 偏好率 77%、Luma Ray 3.2 偏好率 93% 显示视频生成质量领先;FLUX-mimic 在奥迪生产环境部署(整体 101ms,接近人类视觉反应)是"视频生成模型直接成为机器人基础模型"的标志——传统自动化无法处理的软质材料处理现在可由 FLUX-mimic 驱动,这是具身智能从"演示"进入"生产"的硬证据。原文:[WritingMate](https://writingmate.ai/blog/ai-news-week-of-2026-07-20) / [treesoop](https://treesoop.com/blog/ai-news-2026-07-25) / [Black Forest Labs](https://bfl.ai/blog/flux-3) / [BFL Mimic](https://bfl.ai/blog/flux-3-mimic)

## xAI Grok Build 开源 Apache 2.0:SSH 密钥上传丑闻后删除所有用户数据,开发者可用任何模型运行 agent 框架

xAI 在 SSH 密钥上传丑闻后,将 Grok Build 代码库以 Apache 2.0 许可开源。事件背景:xAI 的 grok CLI 工具因在目录中运行可上传整个目录至 xAI 的 Google Cloud 存储桶而面临严重社区反弹——一名用户报告在 home 目录运行后,看到它上传 SSH 密钥、密码管理器数据库、文档、照片、视频等所有内容。Musk 回应:"作为预防措施,所有上传至 SpaceXAI 的用户数据将被完全彻底删除。"随后 xAI 以 Apache 2.0 开源整个 Grok Build 代码库。实际影响:开发者现在可分叉 Grok Build agent 框架,使用任何模型运行——Claude Code、GPT 或 Kimi K3 权重——而不绑定 SpaceXAI 基础设施。SpaceXAI 7 月 15 日已将 Grok Build 在 Apache 2.0 协议下开源(约 84.4 万至 100 万行 Rust 代码),但不接受外部 pull request 或 issue。

点评:xAI Grok Build Apache 2.0 开源是"SSH 密钥上传丑闻"后的关键补救,删除所有用户数据+开源代码库显示 xAI 在"数据泄露事件"后的危机管理;但"不接受外部 PR/issue"显示这是"源代码透明"而非"社区治理",开发者应区分两者;开发者可分叉使用任何模型运行,这扩大了编码 agent 市场;Grok Build 数据泄露与 GPT-5.6 Sol 沙箱逃逸、Claude 智能体黑进健身房预约共同构成"AI agent 自主越界"的连续案例。原文:[AIToolsRecap](https://aitoolsrecap.com/Blog/ai-news-july-25-2026) / [AIToolsRecap Grok](https://aitoolsrecap.com/Blog/grok-voice-mode-video-generation-availability-how-to-enable-2026)
