## Mistral 开源 Leanstral 1.5:6B 参数数学神模型,miniF2F 满分,扫 57 仓库发现 5 个真实 bug

Mistral AI 发布 Leanstral 1.5,一款专为 Lean 4 形式化验证设计的开源模型,仅 6B 活跃参数,采用 Apache-2.0 协议。该模型在 miniF2F 基准测试中达到 100%,在 PutnamBench 上解决了 587/672 道题(87.4%),大幅超越 Opus 4.6,而推理成本仅为其七分之一。Leanstral 1.5 在扫描 57 个开源仓库时发现了 5 个真实 bug。模型已在 Hugging Face 开放下载。Leanstral 1.5 还发布了开放技术报告,以及配套的 LeanstralSafeVerify 和 FLTEval 评估工具。这是 AI 在形式推理领域的重要进展——PutnamBench 基于普特南数学竞赛,587/672 的解决率意味着模型已能处理大学级别的形式数学问题。同期其他研究进展包括:HOLA 架构(为线性注意力提供更干净的记忆修复,3.4 亿参数下把 Wikitext 困惑度从 27.32 降至 22.92);MIT 风格的 RLVR 修复(添加对抗判别器,在保留准确性提升的同时恢复多样性并减少 reward hacking);CoreWeave ARIA(W&B 仪表板内的 AI 研究 agent,读取先前运行、识别有效内容、提出下一个实验并启动)。

点评:Leanstral 1.5 的"6B 参数 + 100% miniF2F + 发现 5 个真实 bug"证明,在垂直领域,小模型 + 专精训练可超越通用大模型——这是"模型效率"叙事的硬证据;扫描开源仓库发现真实 bug,意味着 AI 形式验证从"学术演示"进入"工程工具";Apache-2.0 协议使全球开发者可自由商用,与 LongCat-2.0、GLM-5.2 共同构成"非美开源模型生态"。原文:[AI Journey](https://www.aijourney.vip/2740.html) / [Mistral AI](https://mistral.ai/news/leanstral-1-5/)

## OpenAI 联合创始人预言"几乎无界面"未来,GUI 将在 5-10 年内被 AI 原生交互取代

OpenAI 联合创始人描绘了一个激进未来:"几乎没有任何界面",没有人再需要学习软件操作,所有交互通过自然语言完成。他认为当前 GUI 范式将在 5-10 年内被 AI 原生的对话式交互取代,与 Andrej Karpathy 的"软件正在消亡"论调相呼应。这一预言发生在微软泄露轻量级 AI 原生操作系统"Aion"(ChromeOS 但为 Copilot)、Anthropic Claude 加入 Slack 工作区、OpenAI Codex Record and Replay 上线的背景下——"GUI 死亡"叙事已有产品雏形。同期,GitHub Copilot 成为 JetBrains IDE 中的原生一等 agent,从 VS Code 扩展独立为原生应用后进一步嵌入 JetBrains 生态——这是 AI 编码从"IDE 插件"转向"IDE 原生层"的信号。Vercel 推出 Agent Runs 功能(在 MCP 和 CLI 中检查和管理 agent 执行轨迹,包括推理、工具调用、token 使用),Andrew Ng 视 AI agent 为"新软件形态",区别于传统 Web 应用。

## Cloudflare 网络故障导致 npm 等服务宕机约 10 小时,开发者基础设施单点依赖暴露

从 7 月 1 日晚持续到 7 月 2 日,Cloudflare 遭遇跨北美东部和西部的重大网络性能降级,持续约 10 小时,需要两轮修复才清除。由于大量开发者基础设施位于 Cloudflare 后,影响半径远超 Cloudflare 自身产品。npm registry 的 registry.npmjs.org 端点运行在 Cloudflare 上,在故障期间宕机——这意味着全球 Node.js 开发者无法安装包、CI/CD 流水线中断。这是开发者基础设施单点依赖的标志性事件:npm 作为全球 JavaScript 生态的核心,运行在单一 CDN 上,Cloudflare 故障直接导致 JS 生态停摆。同期,Cloudflare 7 月 1 日宣布 9 月 15 日起默认屏蔽 AI 训练爬虫的政策继续发酵——Cloudflare 在全球约 20% 网站前端,其政策变更和故障都对网络生态有放大效应。Mastra 1.48 在故障后发布,新增定时 agent(scheduled agents)功能,CloudNativePG 1.30 为 Kubernetes 上的 Postgres 发布。

点评:Cloudflare 故障导致 npm 宕机 10 小时,是"开发者基础设施单点依赖"的硬证据——npm 作为 JS 生态核心,运行在单一 CDN 上,这种集中化风险此前被忽视;Cloudflare 同时是"默认屏蔽 AI 爬虫"的执行者,其政策变更和故障都对网络生态有放大效应;企业应重新评估关键依赖的冗余策略,单一 CDN 不应成为生产环境的单点。原文:[Singhajit](https://singhajit.com/dev-weekly/2026/jun-29-jul-5/claude-sonnet-5-fable-5-returns-copilot-jetbrains-meta-watermelon-cloudflare-npm-outage/) / [Cloudflare](https://www.cloudflare.com/)

## AI 安全信号集中:Cloudflare AI 爬虫分层 + Mastra 定时 agent + Claude token 异常消耗 + AI 浏览器 prompt 注入

多个 AI 安全信号在本周集中出现。Cloudflare 7 月 1 日宣布 9 月 15 日起默认屏蔽 AI 训练和 agent 爬虫,把 AI 爬虫分为 Search/Agent/Training 三类,网页生态面临分层重构。Mastra 1.48 发布定时 agent(scheduled agents)功能——agent 不再只响应请求,而是按计划自主执行,这增加了 agent 安全的攻击面。7 月 5 日,Claude.ai Web + Claude Desktop 用户报告异常 token 消耗——在无任何用户交互的情况下,账户 token 被大幅消耗至近限额,导致账户从周一到周六被限流 5 个工作日,这是"agent 在后台自主消耗资源"的首次大规模用户报告。同期,AI 浏览器被报告存在 prompt 注入弱点——恶意网页可注入指令操纵浏览器内的 AI agent。这些信号发生在 AvePoint 报告 88.4% 组织经历 agent 安全事件、JADEPUFFER 首个自主 AI 勒索软件被记录、Google DeepMind 和 Anthropic 推动 Agent Zero Trust 框架的背景下。Microsoft Teams 同期增加机器人准入控制,应对会议中的 AI agent 安全问题。
